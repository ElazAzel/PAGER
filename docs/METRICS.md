# Метрики PAGER

Определения для пилота; демо и тестовые события не включаются в показатели продукта.

| Показатель | Правило |
| --- | --- |
| North Star | Уникальные обращения, впервые получившие подтверждённую запись или успешную оплату за последние 7 суток, на активную опубликованную страницу. |
| Активная страница | Опубликованная страница хотя бы с одним посещением не владельцем в этом окне. При отсутствии активных страниц результат 0. |
| Конверсия | Первая успешная запись или оплата устанавливает `Opportunity.convertedAt`. Последующая оплата той же консультации и продления подписки не создают повторную конверсию. |
| Первая запись за 24 часа | Первая подтверждённая запись в течение 24 часов после регистрации автора. Оплата материала сама по себе не является записью. |
| Повторное обращение | Клиент с конверсией в текущем окне и более ранним отдельным обращением с конверсией. Один клиент учитывается один раз. |
| Выручка | Подтверждённые оплаты показываются отдельно по валютам. USD, EUR и GBP нельзя складывать без явно выбранных курсов. |
| Ошибки | Ошибки оплаты и уведомлений за то же окно; повторная доставка одного события не создаёт новую ошибку. |

Время хранится в UTC. Окно — предыдущие 7 × 24 часа до момента расчёта, без будущих событий. Повторные просмотры одного браузера одной страницы дедуплицируются в пределах суток; это не оценка количества уникальных людей.

Источник истины для конверсии оплаты — подтверждённое сервером событие провайдера. Возврат на страницу после Checkout не подтверждает покупку. История контакта объединяется по нормализованному email только внутри кабинета одного автора.

Эти показатели описывают использование PAGER. Они не подтверждают рыночные оценки или прогнозы ARR из исходного концепта.
