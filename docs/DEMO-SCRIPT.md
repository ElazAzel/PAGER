# PAGER 90-second demo

1. Open a creator's mobile workspace and show the page draft with the readiness checklist.
2. Add or edit the main offer and the booking CTA; publish explicitly.
3. Open the public page as an anonymous visitor and show only public content.
4. Submit a lead or select a booking slot.
5. Continue to the checkout for the associated service or material.
6. Open the creator CRM and show the resulting contact, opportunity and funnel event.
7. End with the product thesis: PAGER connects attention to a measurable business outcome.

State clearly that a local demo uses no real money, calendar events or external notifications. For a live pilot, show only provider events that were actually verified in staging.
