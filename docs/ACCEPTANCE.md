# Приёмка MVP

Этот файл описывает проверки. Отметка в плане разработки или наличие кода не означает, что проверка пройдена. Итоги выполнения фиксируются отдельно, с командой и результатом.

| Область | Сценарий и ожидаемый результат | Среда |
| --- | --- | --- |
| Изоляция | Два автора и два покупателя: чужие черновики, CRM, адреса доставки, заказы и права недоступны через прямые HTTP-запросы и RLS. | API + PostgreSQL |
| Публикация | Изменение черновика не меняет публичную страницу до публикации; устаревшая ревизия не перезаписывает новый черновик. | API + браузер |
| Платный блок | До покупки в HTML, RSC, API и метаданных нет текста, кода, URL и идентификаторов закрытых файлов; покупка открывает только выбранный блок. | API + браузер |
| Платная страница | Доступ открывает новые закрытые блоки, опубликованные после покупки; показанные товары оплачиваются отдельно. | API + браузер |
| История покупок | Повторный вход с другим браузером восстанавливает покупки. Удалённый из композиции проданный материал доступен в библиотеке. | API + браузер |
| Подписка | Оплаченный период открывает доступ; отмена продления сохраняет его до конца периода; неоплаченный следующий период его не продлевает. | События Stripe + Sandbox |
| Возврат и спор | Полный возврат отзывает соответствующее право, спор приостанавливает его; независимая активная покупка продолжает работать. | События Stripe + Sandbox |
| Повтор webhook | Повторная или запоздалая доставка не создаёт вторую конверсию, заказ, право или списание остатка. | Интеграционные тесты |
| Остаток | Два одновременных запроса на последний товар: резерв получает один покупатель. Истечение сессии освобождает резерв ровно один раз. | Транзакции + Sandbox |
| Доставка | Запрещённая страна отклоняется сервером; цена доставки входит в итог до оплаты. Отправку и трек меняет только автор. | API + браузер |
| Консультация | Сначала подтверждается запись, затем оплачивается связанный заказ; неоплата не отменяет встречу. | Cal.com + Stripe Sandbox |
| Напоминания | Перенос и отмена исключают старое уведомление; для встречи менее чем через 24 часа не отправляется просроченное напоминание. | Inngest + тестовые события |
| Email и Telegram | Письмо соответствует выбранному языку. Telegram работает после подключения получателем; без него email и запись работают. | Тестовые получатели |
| 25 блоков | Каждый тип добавляется, редактируется, публикуется и закрывается общим механизмом оплаты; карточки каталога имеют собственные ссылки. | Браузер |
| Редактор | Перетаскивание и клавиатурное перемещение, ширина, копия, скрытие, предпросмотр, публикация; мобильные свойства доступны без горизонтального скролла. | Браузер desktop/mobile |
| Медиа | Форматирование отдельных символов, ссылки, GIF, собственные социальные иконки и защищённая загрузка файлов. | Браузер |
| Код автора | Изолированный iframe выполняет код, но не читает DOM, cookie или сессию родителя. | Браузер |
| Качество | Проверка типов, lint, тесты и production build проходят на итоговых совместных изменениях. | Локально + CI |

Локальные демо-события проверяют пользовательский путь без списания денег и отправки внешних уведомлений. Тестирование SQL в PGlite проверяет исполнение миграции и политик, но не подтверждает работу Supabase Auth, Storage, PostgREST или Docker.

Для проверки внешних интеграций нужен отдельный стабильный HTTPS-стенд, Stripe Sandbox, настроенный аккаунт автора и тестовые получатели. Настоящие платежи не включаются на основании одних фикстур.
