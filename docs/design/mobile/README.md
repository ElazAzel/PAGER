# PAGER: мобильное приложение — новые макеты

Созданы 2026-09-03 после отказа пользователя от всех трёх предыдущих десктопных вариантов. Основное устройство — телефон. Стек остаётся Next.js; интерфейс должен ощущаться как профессионально сделанное мобильное приложение.

Порядок соответствует фактическому показу изображений в разговоре:

1. `01-page-studio.png`: редактор на живом полотне, светлый фон и кобальт.
2. `02-context-sheets.png`: редактирование через контекстную панель, светлый фон, графит и фиолетовый акцент.
3. `03-pocket-editor.png`: компактный список блоков, тёплый светлый фон и зелёный акцент.

Каждый вариант — отдельный результат ImageGen. Целевые пропорции 390 × 844; это изображения приложения без корпуса телефона и системной панели. Использованы требования SPEC и пользовательское уточнение. В новом пустом GitHub-репозитории нет исходного интерфейса. Старые отклонённые макеты не использовались как визуальный образец.

Общее: крупные зоны касания, нижняя навигация, один основной шаг на экране, свойства в отдельной панели, читабельная типографика. Данные Анны Волковой — вымышленный пример; цены не являются реальными предложениями. Вариант 2 показывает состояние редактирования, а не ещё одну страницу продукта.

Выбран вариант 1, `01-page-studio.png`. Он используется как визуальная основа текущего мобильного интерфейса.
